# Slide Deck Standard — TrueSight DAO (mandatory for Sophia & LLM-generated decks)

> Governor directive (Gary Teh, 2026-08-18): *"I like the way the slides were formatted — in the future make sure all Slides generated by Sophia and LLMs follow this format."*
> Origin: `TrueSightDAO_Talk_Deck.pdf` v8 (8-iteration build, approved). Reusable renderer: `truesight_autopilot/templates/slide_deck_template.py`.

## 1. Scope

Every presentation deck generated by Sophia (autopilot) or any LLM tooling for TrueSight DAO / Agroverse MUST follow this format. Exceptions require explicit governor approval.

## 2. Canvas

- **16:9 landscape**, 960 × 540 pt (source images rendered at 1920 × 1080 for full-bleed).
- Built with **reportlab** (PDF canvas) + **PIL** (image crop/resize). `generate_pdf` (markdown-only) is NOT compliant for decks.

## 3. Visual system (Saffron Monk)

| Token | RGB | Use |
|---|---|---|
| SAFFRON | (0.847, 0.463, 0.098) | Header band, accent text |
| CREAM | (0.984, 0.953, 0.894) | Text panels |
| DARK | (0.16, 0.13, 0.09) | Body text |
| GREY | (0.42, 0.38, 0.33) | Secondary text |
| BLUE | (0.10, 0.37, 0.71) | Hyperlinks (underline + link rect) |

- **Fonts:** Helvetica family — `Helvetica-Bold` titles (23–27pt), `Helvetica-Oblique` subtitles (11.5–13pt), `Helvetica` body (12–12.5pt).
- **Header band:** saffron, 34pt tall, full width at top; white bold 9pt centered band text `TRUE·SIGHT DAO × AGROVERSE · <EVENT TITLE>`; right-aligned page number `<n> / <total>`.
- **Footer:** white @ 75% alpha, 8pt, right-aligned: `truesight.me · agroverse.shop · TrueSight DAO`.

## 4. Layout rules

- **Full-bleed photo background** per slide: 16:9 center-crop, LANCZOS resize, JPEG q82.
- **Dim overlay** alpha 0.50–0.55 over the photo (black) for text legibility.
- Text sits in a **cream rounded-rect panel** (radius 8, alpha ~0.88), left margin 40, panel width 540–620.
- Titles 23–27pt, subtitles 11.5–13pt italic, bullets 12–12.5pt with 21pt leading and 8pt gap between items.

## 5. Text rules (MUST)

1. **Every text element wraps to its panel width** — measured with `stringWidth` and wrapped word-by-word (`draw_wrapped` helper). Raw `drawString` without wrapping is forbidden; **nothing may overspill the box**. (Root cause of a real defect: slide-1 teaser line drawn with `drawString` at ~110 chars → overspill. Fixed by the wrap helper.)
2. Bullets: `•` marker at x, text at x+18, wrapped at `maxw-18`.
3. Titles wrap to ≤2 lines; kicker/teaser lines wrap within the panel.

## 6. Link rules (MUST)

1. **Every line item / bullet that refers to a real thing is a clickable link to the ACTUAL artifact** — the tool page, JSON source, repo, or program page the text describes, NOT a generic homepage. E.g. "shipping planner" → `dapp.truesight.me/shipping_planner.html`, "Sheets source of truth" → the public treasury JSON, "Beer Hall digest" → the beerhall archive JSON.
2. Links render **blue + underlined**, with a `linkURL` rect spanning each wrapped line.
3. **URLs are verified live (HTTP 200) before embedding** — never guess a target.
4. QR-code images link to the real trace/farm/registry page they represent.
5. When a private artifact (e.g. Google Sheet, Telegram channel) is the topic, link the public mirror/export instead — never expose auth-gated or internal URLs.

## 7. Generation checklist (every deck)

1. Curate **authentic photos** from DAO archives (`agroverse_shop_beta`, `sunmint`, `lineage-assets`, `truesight_me_prod`) — verify each is a valid image + dimensions.
2. Crop to 16:9, dim for legibility.
3. **Copy grounded in runbooks** — `read_context_file` the relevant docs before writing claims (supply chain, TrueChain, growth model, etc.).
4. Wrap every string; verify no overspill.
5. Link every line item to verified-live URLs.
6. Validate output: PDF 1.4+, correct page count, `/URI` count matches expected links.
7. **Run the automated overlap check (MANDATORY):** `python3 scripts/verify_pdf_slides.py <deck>.pdf`
   (from `truesight_autopilot`, PR #303) must exit **0**. It audits all four overlap
   classes that have caused real defects: text×text, text×image (full-bleed background
   photos exempt by design), text×panel (words spilling over content-panel edges —
   the bug that painted over titles), and panel×header/footer (panels intruding into
   the saffron band). **No deck is sent to a governor unless this passes.**
8. Send PDF to the governor for review; iterate; log the contribution only after approval.
