## 1. 论点

中国制造商的短板不在产能，而在**可验证的溯源**——这一缺口使其 ESG 评级被压制在欧美制造商所持 AAA 级之下，进而阻碍欧盟/美国市场准入。中国有条件**出口其数字化**：向各国制造商提供供应链溯源数字化服务。TrueSight 谱系技术栈正是让这一服务成真的证据层——而且它**今天已在巴西运营**；巴西是金砖成员，也是中国最大的贸易伙伴之一。

## 2. 问题：评级缺口

- 欧美制造商能持顶级（AAA）ESG 评级，是因为其证据结构化、经审计、可验证。
- 中国制造商——能力相当——却因证据零散、以纸质为主、无法独立验证而被降级或被扣留（欧盟 CSRD/CSDDD/EUDR；美国 UFLPA 及 CBP 2026 年 6 月操作指南）。
- 金砖与一带一路各国的制造商同样面临这一缺口。

## 3. 资产：我们的技术栈，已在巴西运营

已在巴西"从农场到巧克力"可可供应链上验证：

| 层级 | 功能 |
|---|---|
| 单品级二维码序列化 | 每件商品可识别、可扫码（1,457+ 件已上线） |
| 谱系清单 | 每件商品的仅可追加 JSON 历史（来源、加工、保管、事件） |

| 文件公证 | 审计、认证、用工记录经哈希并关联到商品 |
| 公开验证 | 扫码 → 数秒内查看完整溯源与证据 |
| 数据本地化设计 | 按辖区部署（lineage-assets-china、-brazil 等） |

## 4. 打法：出口数字化

| 集团 | 国家 | 打法 |
|---|---|---|
| **金砖 (BRICS)** | 巴西、中国、印度、俄罗斯、南非、印尼、沙特、阿联酋、埃及、埃塞俄比亚、伊朗 | 在每个成员国为制造商部署；辖区内存放；跨境验证经 API |
| **一带一路 (BRI)** | 150+ 伙伴国家 | 国别模板（纺织、电子、农产品、机械）；国家级验证门户；联合国 SDG 对齐 |

**成果：** 制造商获得**可验证的 ESG 证据 → AAA 评级 → 欧盟/美国市场准入**——所用技术栈与中国自身一致。中国出口数字化，而不仅仅是商品。

## 5. 为什么成立（以及为什么是我们）

- **生产级验证**（巴西、可可）——不是演示。
- **可扩展数据模型**：任何资产类型免重构接入。
- **防篡改 + 开放验证** → 赢得欧美买家与审计方信任。
- **数据本地化设计** → 契合各国法规。
- **SDG 对齐**：SDG 8（体面工作）、9（产业/创新/基础设施）、12（负责任消费和生产）、17（伙伴关系）——联合国可采信的叙事。
