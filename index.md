# Agentic AI Context

Public read-only mirror of [TrueSightDAO/agentic_ai_context](https://github.com/TrueSightDAO/agentic_ai_context),
served straight from the `main` branch via GitHub Pages. This repo holds **workspace context** for AI
coding assistants (Claude Code, OpenAI Codex, Gemini CLI, Cursor, etc.) working on TrueSight DAO / Agroverse.

This is a bare GitHub Pages site (no theme, no site generator) — pages below are the raw Markdown source,
not a styled docs site. For a browsable file tree, use the [GitHub repo](https://github.com/TrueSightDAO/agentic_ai_context)
directly.
